1. Motivación

Con muchas variables se complican varias cosas a la vez. No podemos visualizar más de dos o tres dimensiones, muchas variables suelen estar correlacionadas y repiten información, y aparece la maldición de la dimensionalidad que vimos con KNN. PCA responde a una pregunta concreta: ¿cuáles son las pocas direcciones del espacio de variables que capturan la mayor parte de la variación de los datos?

El resultado es un nuevo sistema de ejes, las componentes principales, ordenados por cuánta varianza capturan. Cada eje es una combinación lineal de las variables originales.

2. Formalización

Sea X ∈ ℝn×d ya centrada: cada columna tiene media cero. La primera componente principal es la dirección unitaria w₁ que maximiza la varianza de los datos proyectados sobre ella:

La segunda componente w₂ resuelve el mismo problema con la restricción de ser ortogonal a w₁, y así sucesivamente hasta d componentes.

Hay una segunda lectura del mismo problema. Proyectar un punto sobre una recta deja un residuo: el segmento perpendicular entre el punto y su proyección. Por Pitágoras, la varianza proyectada más el error cuadrático medio de reconstrucción suman siempre la varianza total. Así que maximizar la varianza proyectada equivale a minimizar el error de reconstrucción.

3. De dónde sale la solución

Maximizar wᵀΣw sujeto a ‖w‖ = 1 es una optimización con restricción. La resolvemos con un multiplicador de Lagrange:

Derivamos respecto a w e igualamos a cero:

Es la ecuación de eigenvectores. Si multiplicamos ambos lados por wᵀ, queda wᵀΣw = λ: la varianza capturada por un eigenvector es su eigenvalor. Para maximizarla tomamos el eigenvector con el eigenvalor más grande. La segunda componente es el del segundo eigenvalor, y así sucesivamente.

Como Σ es simétrica, sus eigenvectores son ortogonales entre sí. Por eso las proyecciones sobre componentes distintas nunca están correlacionadas: cada componente captura variación que las anteriores no habían capturado.

4. La otra forma de calcularlo: SVD

En la práctica casi nunca formamos Σ para sacar sus eigenvectores, porque es numéricamente menos estable. Usamos la descomposición en valores singulares de la matriz centrada:

  • Las columnas de V son las componentes principales, los mismos eigenvectores de Σ.
  • Los valores singulares sᵢ dan los eigenvalores.
  • US son los scores: cada observación expresada en el nuevo sistema de coordenadas.

sklearn.decomposition.PCA usa SVD por debajo. "Componentes principales" y "eigenvectores de la covarianza" son el mismo objeto calculado por dos caminos.

5. Cuántas componentes usar

Cada componente explica una proporción de la varianza total:

  • Scree plot: graficamos la proporción explicada por componente y buscamos el codo, con la misma lógica que en K-means.
  • Varianza acumulada objetivo: nos quedamos con las primeras componentes que juntas explican, por ejemplo, 90 o 95 %.

La respuesta depende del objetivo. Para visualizar usamos dos o tres componentes, expliquen lo que expliquen. Para comprimir o preprocesar antes de otro modelo sí importa retener suficiente varianza, y conviene elegir el número con validación cruzada sobre el modelo final.

6. Centrar y escalar

PCA busca direcciones de máxima varianza alrededor del origen. Si no centramos, la primera "componente" apunta hacia la media de los datos en lugar de seguir su variación. Y si las variables están en escalas distintas, la que tiene mayor varianza numérica domina la varianza total, sea o no la más informativa. El flujo estándar es estandarizar y después aplicar PCA, salvo que todas las variables ya estén en unidades comparables por diseño. Estandarizar equivale a hacer PCA sobre la matriz de correlación en lugar de la de covarianza.

7. Interpretar las componentes

Cada componente es una combinación lineal PC₁ = w₁₁x₁ + w₁₂x₂ + … + w₁dxd. Los coeficientes son los loadings: cuánto pesa cada variable original en esa componente. Mirar los loadings más grandes en valor absoluto suele dar una interpretación. En la figura 2, ya estandarizada, la PC1 carga en horas de estudio, asistencia y calificación, y la podemos leer como un eje de compromiso académico. El signo de una componente es arbitrario: w y −w capturan la misma varianza.

8. Limitaciones

  • Solo relaciones lineales. Si la estructura es curva, como una espiral, PCA no la encuentra. Para eso están t-SNE y UMAP, y los autoencoders de la Fase 7.
  • Sensible a outliers, igual que la media y la varianza en las que se basa.
  • Más varianza no siempre significa más información útil. Si el objetivo final es clasificar, la dirección de mayor varianza no tiene por qué ser la que mejor separa las clases. LDA (linear discriminant analysis) sí usa las etiquetas.
  • Mezcla todas las variables. A diferencia de Lasso (Fase 4), PCA no elige un subconjunto de variables interpretable: cada componente usa todas.

9. Implementación

Desde cero, con eigenvectores de la covarianza:

import numpy as np

def pca(X, n_components):
    X_centered = X - X.mean(axis=0)
    cov = np.cov(X_centered, rowvar=False)
    eigenvalues, eigenvectors = np.linalg.eigh(cov)   # eigh: matrices simétricas

    order = np.argsort(eigenvalues)[::-1]              # de mayor a menor
    eigenvalues = eigenvalues[order]
    eigenvectors = eigenvectors[:, order]

    components = eigenvectors[:, :n_components]
    scores = X_centered @ components
    explained_variance_ratio = eigenvalues[:n_components] / eigenvalues.sum()
    return scores, components, explained_variance_ratio

Con scikit-learn. Si PCA va antes de un modelo supervisado, lo metemos en un pipeline para que se ajuste solo con los datos de entrenamiento de cada fold:

from sklearn.decomposition import PCA
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

pipe = make_pipeline(StandardScaler(), PCA(n_components=0.90))
scores = pipe.fit_transform(X)        # 0.90: elige k para retener 90 %

pca = pipe.named_steps["pca"]
print(pca.explained_variance_ratio_)           # por componente
print(pca.explained_variance_ratio_.cumsum())  # acumulada
print(pca.components_)                         # loadings
