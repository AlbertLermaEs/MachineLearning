1. El dataset

load_wine tiene 178 vinos de tres productores de la misma región de Italia, con 13 mediciones químicas: alcohol, acidez, fenoles, flavonoides, intensidad de color, prolina y otras. Las escalas son muy distintas: la prolina va de unos 280 a 1680, mientras el tono va de 0.5 a 1.7.

from sklearn.datasets import load_wine

X, y = load_wine(return_X_y=True, as_frame=True)
X.shape                     # (178, 13)
X.std().sort_values().tail(2)   # magnesium ≈ 14, proline ≈ 315

2. Código paso a paso

Primero estandarizamos y después ajustamos PCA, dentro de un pipeline. Si pasamos un número entre 0 y 1 como n_components, PCA elige cuántas componentes hacen falta para conservar esa fracción de la varianza.

from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

pca = make_pipeline(StandardScaler(), PCA(n_components=0.95))
Z = pca.fit_transform(X)
Z.shape                                    # (178, 10)
pca[-1].explained_variance_ratio_.round(3)

Para graficar fijamos dos componentes. Cada fila de Z es un vino en coordenadas nuevas.

import matplotlib.pyplot as plt

Z2 = make_pipeline(StandardScaler(), PCA(n_components=2)).fit_transform(X)
plt.scatter(Z2[:, 0], Z2[:, 1], c=y)   # y solo para colorear

3. Cuántas componentes

La gráfica de varianza explicada, o scree plot, es la herramienta para decidirlo. Con los datos sin escalar, la decisión se vuelve trivial por una mala razón.

Sin escalar, PCA no encuentra estructura química: encuentra la unidad de medida más grande. Es el mismo problema que vimos con K-means y KNN, y la solución es la misma.

Si PCA es un paso previo a un modelo supervisado, el número de componentes se vuelve un hiperparámetro más y lo elegimos con validación cruzada. En ese caso sí separamos train y test, y PCA se ajusta solo con train dentro del pipeline:

from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import GridSearchCV, train_test_split

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, stratify=y, random_state=42)
pipe = make_pipeline(StandardScaler(), PCA(), LogisticRegression(max_iter=1000))
grid = GridSearchCV(pipe, {"pca__n_components": range(1, 14)}, cv=5)
grid.fit(X_train, y_train)
grid.best_params_

4. Cómo interpretar la salida

components_ tiene una fila por componente y una columna por variable: son los loadings. Una variable con loading grande, positivo o negativo, pesa mucho en esa dirección. En los vinos estandarizados, la primera componente pesa sobre todo en fenoles, flavonoides y proantocianinas, que se mueven juntos.

import pandas as pd

p = pca[-1]
cargas = pd.DataFrame(p.components_[:2].T, index=X.columns,
                      columns=["PC1", "PC2"])
cargas.sort_values("PC1")

El signo de una componente es arbitrario: multiplicarla por −1 da la misma dirección. Lo que importa es qué variables tienen el mismo signo dentro de una componente. inverse_transform reconstruye los datos originales desde las componentes conservadas; la diferencia con X es el error de reconstrucción.

5. Errores frecuentes

  • No escalar con variables en unidades distintas. La primera componente copia a la variable de mayor varianza, como en la figura 1.
  • Ajustar PCA con todos los datos antes de separar. Si después viene un modelo supervisado, PCA va dentro del pipeline.
  • Interpretar el signo. Que PC1 sea positiva para un vino no significa nada por sí solo; se lee junto con los loadings.
  • Suponer que la varianza alta es la útil. PCA no mira y. La dirección que separa las clases puede tener poca varianza y quedar fuera.
  • Usarlo con relaciones no lineales. PCA solo encuentra direcciones rectas. Para visualizar estructura curva, ver t-SNE o UMAP.
