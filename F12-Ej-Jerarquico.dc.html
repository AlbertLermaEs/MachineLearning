Clustering jerárquico · Ejemplos por modelo
Curso de Machine Learning Fase 12 · Ejemplos por modelo

Teoría: Fase 3 · Clustering jerárquico · scikit-learn 1.9.1

1. El dataset

Para este ejemplo generamos los datos con make_moons: dos medias lunas entrelazadas. Ningún método que busque grupos redondos las separa bien, y por eso sirven para ver en qué se distinguen los criterios de enlace. noise es la desviación estándar del ruido gaussiano que se suma a cada punto.

from sklearn.datasets import make_moons

X, y = make_moons(n_samples=120, noise=0.08, random_state=0)
X.shape    # (120, 2); y solo para comparar al final

2. Código paso a paso

Primero ajustamos. Las dos variables ya están en la misma escala; con datos reales escalaríamos antes. AgglomerativeClustering no tiene predict: las etiquetas salen del mismo ajuste.

from sklearn.cluster import AgglomerativeClustering

hc = AgglomerativeClustering(n_clusters=2, linkage="single")
etiquetas = hc.fit_predict(X)
hc.n_leaves_, hc.children_.shape   # 120 hojas, 119 fusiones

Después comparamos contra las lunas reales con ARI, igual que en K-means.

from sklearn.metrics import adjusted_rand_score

adjusted_rand_score(y, etiquetas)

Si en vez de fijar el número de clusters queremos cortar el dendrograma a una altura, pasamos distance_threshold con n_clusters=None.

hc = AgglomerativeClustering(n_clusters=None, distance_threshold=0.5,
                             linkage="single").fit(X)
hc.n_clusters_          # cuántos clusters quedaron bajo esa altura
hc.distances_[-5:]      # alturas de las últimas fusiones

3. Criterio de enlace

linkage define la distancia entre dos grupos y cambia por completo el resultado. Con "single" y poco ruido, el enlace sigue cada luna punto a punto; al subir el ruido, aparecen puntos sueltos entre las lunas.

tamaños{{ sizes }} ARI contra las lunas{{ ari }}
{{ desc }}

Single es el único que recupera formas no convexas, pero es el más frágil: con ruido, la última fusión puede ser un punto aislado en vez de la otra luna, o un puente de puntos puede unir las dos. Es el efecto cadena que vimos en la teoría. Los otros tres criterios prefieren grupos compactos y cortan las lunas.

4. Cómo interpretar la salida

El dendrograma no lo dibuja scikit-learn. La forma directa es con SciPy, que usa los mismos criterios de enlace. La altura de cada unión es la distancia entre los grupos que se fusionaron; un salto grande entre alturas consecutivas sugiere dónde cortar.

from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
import matplotlib.pyplot as plt

Z = linkage(X, method="ward")
dendrogram(Z, truncate_mode="lastp", p=20)
plt.show()

etiquetas = fcluster(Z, t=2, criterion="maxclust")   # de 1 a 2

children_ guarda las fusiones en orden: en el paso i se unen los nodos children_[i]. Los índices menores que n son puntos originales; los mayores, grupos creados en pasos anteriores.

5. Errores frecuentes

  • Usar ward con otra métrica. Ward solo funciona con distancia euclidiana. Para otras métricas usamos "average" o "complete" con metric=.
  • Elegir single sin mirar el ruido. Un solo puente de puntos une dos grupos. Revisamos los tamaños de los clusters: uno de tamaño 1 es una señal.
  • Esperar predict. Para asignar puntos nuevos, entrenamos un clasificador (por ejemplo KNN) con X y las etiquetas obtenidas.
  • Aplicarlo a datos grandes. Necesita la matriz de distancias completa: memoria cuadrática en el número de puntos. Para decenas de miles, una opción es pasar connectivity con un grafo de vecinos.
  • Comparar alturas entre criterios. La escala de distances_ depende del enlace; ward da alturas mucho mayores que single.
