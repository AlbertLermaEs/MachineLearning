Tipos de variables

Las variables cuantitativas miden cantidades: continuas si pueden tomar cualquier valor en un rango, discretas si cuentan cosas. Las cualitativas o categóricas nombran grupos: nominales sin orden, ordinales con orden pero sin una distancia numérica clara. Las binarias son nominales con dos categorías.

{{ vsel.title }} {{ vsel.desc }}

El tipo importa porque un modelo lineal no puede usar directamente una nominal: no tiene sentido multiplicar "rojo" por un coeficiente. Necesita codificación, que veremos en Preprocesamiento. Una ordinal a veces sí se trata como numérica, si el espaciado entre niveles tiene sentido.

Describir antes de graficar

Para la tendencia central tenemos la media, la mediana y la moda (la única que aplica a categóricas). Para la dispersión, varianza, desviación estándar, rango y rango intercuartílico, IQR = Q3 − Q1. Para la forma, el sesgo (skewness) y la curtosis. La diferencia entre media y mediana se entiende mejor moviendo un solo dato.

Un sesgo positivo significa cola larga a la derecha, como los ingresos; uno negativo, cola larga a la izquierda. La curtosis mide qué tan pesadas son las colas comparadas con una normal. Los cuantiles, df["col"].quantile([0.25, 0.5, 0.75]), son la base del boxplot.

Principios de una buena visualización

  • Cada gráfica responde una pregunta. Si no podemos decir en una frase cuál, sobra o le falta contexto.
  • Minimizar el chartjunk. Cuadrículas pesadas, 3D innecesario, colores decorativos. El principio de Tufte: maximizar la proporción dato-tinta.
  • El eje Y de una barra empieza en cero. En líneas y dispersión sí puede tener sentido acotar el rango.
  • Color con propósito. Secuencial para numéricas ordenadas, cualitativa para categorías, divergente cuando hay un punto medio con significado (correlaciones de −1 a 1).
  • Etiquetar todo. Título, ejes con unidades, leyenda.

Cosas a vigilar al leer una gráfica

Un histograma con pocos bins puede ocultar que los datos tienen dos modas; con demasiados, ocultar la forma general. Conviene probar varios valores de bins.

{{ hist.desc }}

En un scatter con muchos puntos superpuestos la densidad real se esconde: usamos alpha, sns.kdeplot en 2D o un hexbin. Un boxplot esconde el tamaño de muestra: un grupo de 3 observaciones se ve igual de sólido que uno de 3000, así que siempre verificamos n por grupo.

Y dos cuidados con la correlación. Primero, correlación no implica causalidad: puede haber una variable confusora detrás, o causalidad inversa. Segundo, el coeficiente de Pearson solo mide relación lineal.
