Teoría: Fase 3 · t-SNE y UMAP · scikit-learn 1.9.1

1. El dataset

load_digits tiene 1797 imágenes de dígitos escritos a mano, de 8 × 8 píxeles, con intensidades de 0 a 16. Cada imagen es un vector de 64 variables. Es el ejemplo clásico para t-SNE: en 64 dimensiones no podemos ver nada, y en dos queremos saber si los dígitos forman grupos.

from sklearn.datasets import load_digits

X, y = load_digits(return_X_y=True)
X.shape    # (1797, 64)

2. Código paso a paso

Primero reducimos con PCA a unas 30 o 50 dimensiones. Quita ruido y acelera t-SNE, que compara todos los pares de puntos. Los píxeles ya comparten escala, así que aquí no estandarizamos.

from sklearn.decomposition import PCA

X_pca = PCA(n_components=30, random_state=0).fit_transform(X)

Después corremos t-SNE. Solo tiene fit_transform: no aprende una función que se pueda aplicar a puntos nuevos.

from sklearn.manifold import TSNE

tsne = TSNE(n_components=2, perplexity=30, init="pca",
            max_iter=1000, random_state=0)
emb = tsne.fit_transform(X_pca)   # (1797, 2)
tsne.kl_divergence_               # costo final

Finalmente graficamos, usando y solo para colorear.

import matplotlib.pyplot as plt

plt.scatter(emb[:, 0], emb[:, 1], c=y, cmap="tab10", s=6)
plt.colorbar()

3. Perplejidad, inicialización y semilla

perplexity es el número efectivo de vecinos que mira cada punto; el valor por defecto es 30 y debe ser menor que el número de puntos. init="pca" es el valor por defecto desde la versión 1.2 y suele conservar mejor la estructura global que "random".

Un mapa de t-SNE no es un resultado único. Antes de concluir algo, lo repetimos con dos o tres perplejidades y semillas y nos quedamos con lo que se mantiene en todas.

4. Cómo interpretar la salida

Las coordenadas de emb no tienen unidades ni significado por sí solas. Se puede leer qué puntos quedan cerca de cuáles: si dos imágenes son vecinas en el mapa, probablemente lo son en 64 dimensiones. No se puede leer el tamaño de un grupo ni la distancia entre grupos. kl_divergence_ sirve para comparar corridas con la misma perplejidad, no entre perplejidades distintas.

Si necesitamos proyectar puntos nuevos sobre un mapa ya ajustado, UMAP sí tiene transform. No viene en scikit-learn; está en el paquete umap-learn, con la misma API:

import umap   # pip install umap-learn

red = umap.UMAP(n_neighbors=15, min_dist=0.1, random_state=0)
emb_u = red.fit_transform(X_pca)
red.transform(X_pca[:5])   # proyecta puntos nuevos

5. Errores frecuentes

  • Usar t-SNE como preprocesamiento. No tiene transform y el mapa cambia con cada corrida; no sirve como entrada de un modelo supervisado. Para eso está PCA.
  • Leer tamaños y distancias entre grupos. t-SNE ajusta la escala a la densidad local de cada punto. Solo la vecindad es confiable.
  • Una sola perplejidad. Valores muy bajos fabrican grumos; valores muy altos juntan grupos. Comparamos varios.
  • Correrlo sobre datos crudos de alta dimensión. Con cientos de variables conviene pasar antes por PCA a unas 50.
  • Usar el nombre viejo del parámetro. Desde la versión 1.5, el número de iteraciones se llama max_iter; n_iter ya no existe.
