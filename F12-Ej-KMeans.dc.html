Teoría: Fase 3 · K-means · scikit-learn 1.9.1

1. El dataset

Usamos otra vez load_iris, ahora sin mirar y para ajustar. Es un buen caso de prueba para clustering porque sí conocemos la respuesta: después de agrupar podemos comparar contra las tres especies y ver qué tanto recuperó el algoritmo por su cuenta.

from sklearn.datasets import load_iris

X, y = load_iris(return_X_y=True, as_frame=True)
X.shape    # (150, 4); y solo se usa al final para comparar

2. Código paso a paso

Primero escalamos. K-means minimiza distancias euclidianas al cuadrado, así que una variable con más rango pesaría más. En clustering no hay train y test: ajustamos con todos los datos.

from sklearn.preprocessing import StandardScaler

X_esc = StandardScaler().fit_transform(X)

Después ajustamos. n_init repite el algoritmo con distintas inicializaciones k-means++ y se queda con la de menor inercia; "auto" usa una sola corrida con k-means++.

from sklearn.cluster import KMeans

km = KMeans(n_clusters=3, n_init=10, random_state=42)
etiquetas = km.fit_predict(X_esc)
km.cluster_centers_   # (3, 4), en escala estandarizada
km.inertia_           # suma de distancias² al centroide
km.n_iter_            # iteraciones de Lloyd

Finalmente, evaluamos. Sin etiquetas usamos silhouette; aquí, como sí las tenemos, también comparamos con ARI, que vale 1 si los grupos coinciden con las especies y alrededor de 0 si son aleatorios.

from sklearn.metrics import silhouette_score, adjusted_rand_score

silhouette_score(X_esc, etiquetas)
adjusted_rand_score(y, etiquetas)

3. Elegir k

inertia_ siempre baja al subir k, así que no sirve sola para elegir. Silhouette compara, para cada punto, la distancia media a su propio cluster con la del cluster vecino más cercano.

inertia_{{ inertia }} silhouette_score{{ sil }} adjusted_rand_score{{ ari }}
Silhouette por k
{{ desc }}

El silhouette y la respuesta correcta no tienen por qué coincidir. Silhouette premia grupos compactos y separados; si dos especies se tocan, para el algoritmo son un solo grupo. Elegir k es una decisión que combina métricas con lo que sabemos del problema.

for k in range(2, 9):
    km = KMeans(n_clusters=k, n_init=10, random_state=42).fit(X_esc)
    print(k, round(km.inertia_, 1),
          round(silhouette_score(X_esc, km.labels_), 3))

4. Cómo interpretar la salida

Los números de cluster son arbitrarios: el cluster 0 de una corrida puede ser el 2 de otra. Para describirlos miramos los centroides en las unidades originales y una tabla cruzada contra lo que sepamos de los datos.

import pandas as pd

esc = StandardScaler().fit(X)
km = KMeans(n_clusters=3, n_init=10, random_state=42).fit(esc.transform(X))
pd.DataFrame(esc.inverse_transform(km.cluster_centers_), columns=X.columns)
pd.crosstab(y, km.labels_)   # filas: especie, columnas: cluster

KMeans tiene predict: asigna un punto nuevo al centroide más cercano. Por eso puede ir dentro de un pipeline y aplicarse a datos que llegan después, a diferencia de DBSCAN o del clustering jerárquico.

5. Errores frecuentes

  • No escalar. Con variables en unidades distintas, los clusters se forman casi solo sobre la de mayor rango.
  • Leer el número de cluster como una clase. labels_ no tiene orden ni significado; para compararlo con etiquetas usamos ARI o una tabla cruzada, nunca accuracy directo.
  • Elegir k con la inercia. Siempre baja al subir k. Usamos el codo, silhouette o conocimiento del problema.
  • Una sola inicialización. Lloyd converge a un mínimo local. n_init mayor que 1 reduce el riesgo.
  • Usarlo con grupos alargados o de densidad distinta. K-means supone grupos redondos de tamaño parecido. Para otras formas están GMM, DBSCAN o el clustering jerárquico.
