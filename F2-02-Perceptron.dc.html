1. Contexto

Frank Rosenblatt propuso el perceptrón en 1958, inspirado de forma libre en una neurona biológica. Es el antecesor directo de las redes neuronales modernas: cada neurona de una red densa, que veremos en la Fase 8, es esencialmente un perceptrón con otra función de activación.

A diferencia de KNN, que no aprende ningún parámetro, el perceptrón construye un modelo explícito. Es nuestro primer ejemplo formal del paradigma paramétrico de la introducción.

2. El modelo

El perceptrón es un clasificador lineal binario. Con etiquetas y ∈ {−1, +1} y una entrada x ∈ ℝᵈ, predice:

w es el vector de pesos y b el sesgo (bias, que no tiene relación con el sesgo estadístico de sesgo-varianza). Geométricamente, wᵀx + b = 0 es un hiperplano que divide el espacio en dos; el signo dice de qué lado cae x, y w apunta hacia el lado positivo. Por convención absorbemos b en w agregando una coordenada constante x₀ = 1, y escribimos ŷ = sign(wᵀx).

En el vocabulario de la introducción, el espacio de hipótesis ℋ del perceptrón es el conjunto de todos los hiperplanos de ℝᵈ. Elegir este algoritmo es elegir ese ℋ, y por eso su frontera siempre es recta.

3. El algoritmo de aprendizaje

El aprendizaje es online: procesa un ejemplo a la vez, y solo cambia los pesos cuando se equivoca.

Inicializar w = 0
Repetir hasta que no haya errores (o hasta max_iter):
    Para cada (x_i, y_i) del conjunto de entrenamiento:
        Si sign(w^T x_i) != y_i:
            w = w + y_i * x_i

Si un punto positivo (yᵢ = +1) queda del lado negativo, sumar xᵢ a w aumenta wᵀxᵢ en ‖xᵢ‖², así que el hiperplano gira hacia clasificarlo bien. Con un falso positivo restamos xᵢ y pasa lo contrario. Una sola actualización no siempre arregla el punto, pero siempre lo acerca.

4. Teorema de convergencia (Novikoff, 1962)

La cantidad R/γ vale la pena recordarla: reaparece casi idéntica en la teoría de SVM (Fase 5). La diferencia es que SVM busca el hiperplano que maximiza el margen, mientras que el perceptrón se detiene en el primero que separa, como se ve en la figura: su frontera casi nunca coincide con la punteada.

5. La limitación: datos no separables

Si los datos no son linealmente separables, el algoritmo básico nunca converge: sigue oscilando. El ejemplo clásico es XOR. No hay recta que separe (0, 0) y (1, 1) de (0, 1) y (1, 0).

Minsky y Papert usaron este argumento en su libro Perceptrons (1969) para mostrar los límites del modelo de una sola capa. El libro contribuyó al primer "invierno de la IA", un enfriamiento de más de una década en la investigación de redes neuronales. Lo resolvieron el backpropagation y las redes multicapa (Fase 8), que introducen no linealidades entre capas.

En la práctica, para datos no separables usamos variantes: el perceptrón con margen, el pocket algorithm, que se queda con los mejores pesos vistos en lugar de los últimos, o modelos con pérdida suave como la regresión logística y la SVM de margen suave, que veremos en la Fase 5.

7. Implementación

import numpy as np

class Perceptron:
    def __init__(self, lr=1.0, max_iter=1000):
        self.lr = lr
        self.max_iter = max_iter

    def fit(self, X, y):
        # y debe estar en {-1, +1}
        X = np.hstack([np.ones((X.shape[0], 1)), X])  # columna de bias
        self.w = np.zeros(X.shape[1])

        for _ in range(self.max_iter):
            errors = 0
            for xi, yi in zip(X, y):
                if np.sign(self.w @ xi) != yi:
                    self.w += self.lr * yi * xi
                    errors += 1
            if errors == 0:
                break  # convergió

    def predict(self, X):
        X = np.hstack([np.ones((X.shape[0], 1)), X])
        return np.sign(X @ self.w)

En scikit-learn, Perceptron acepta etiquetas en cualquier formato y comparte implementación con SGDClassifier: equivale a SGDClassifier(loss="perceptron", learning_rate="constant", eta0=1, penalty=None). Como usa descenso de gradiente, conviene escalar las variables.

from sklearn.linear_model import Perceptron
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
