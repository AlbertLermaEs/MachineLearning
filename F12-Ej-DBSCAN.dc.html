Teoría: Fase 3 · DBSCAN · scikit-learn 1.9.1

1. El dataset

Volvemos a make_moons, ahora con 200 puntos y una docena de puntos aislados agregados a mano. Queremos dos cosas que K-means no puede dar: grupos con forma arbitraria y una etiqueta explícita para los puntos que no pertenecen a ningún grupo.

import numpy as np
from sklearn.datasets import make_moons

X, y = make_moons(n_samples=200, noise=0.07, random_state=0)
rng = np.random.default_rng(0)
atipicos = rng.uniform([-1.4, -0.9], [2.4, 1.4], size=(12, 2))
X = np.vstack([X, atipicos])

2. Código paso a paso

Primero ajustamos. eps es el radio de vecindad, en las unidades de X; min_samples es cuántos puntos debe haber dentro de ese radio, contando al propio punto, para que sea núcleo. Los valores por defecto (0.5 y 5) casi nunca son los correctos.

from sklearn.cluster import DBSCAN

db = DBSCAN(eps=0.25, min_samples=5).fit(X)
etiquetas = db.labels_          # -1 es ruido
db.core_sample_indices_         # índices de los puntos núcleo

Después contamos. El número de clusters no es un parámetro de entrada: sale del ajuste.

n_clusters = len(set(etiquetas)) - (1 if -1 in etiquetas else 0)
n_ruido = (etiquetas == -1).sum()

3. Elegir eps y min_samples

Una regla práctica es fijar min_samples (por ejemplo, el doble del número de variables) y elegir eps con la gráfica de k-distancias: para cada punto, la distancia a su vecino número min_samples − 1, ordenada de menor a mayor. El codo de esa curva separa los puntos de zonas densas de los aislados.

núcleoruido

La misma gráfica se calcula con NearestNeighbors. Pedimos min_samples vecinos porque el primero de cada fila es el propio punto, a distancia cero:

from sklearn.neighbors import NearestNeighbors
import matplotlib.pyplot as plt

nn = NearestNeighbors(n_neighbors=5).fit(X)
dist, _ = nn.kneighbors(X)
plt.plot(np.sort(dist[:, -1]))
plt.axhline(0.25, ls="--")    # el eps que estamos probando

4. Cómo interpretar la salida

Hay tres tipos de punto. Los núcleo tienen al menos min_samples puntos en su radio. Los de frontera están en el radio de un núcleo sin serlo ellos. El resto es ruido y recibe la etiqueta −1. Los puntos de frontera que alcanzan dos clusters se asignan al primero que los encuentra, así que esa parte depende del orden de los datos.

es_nucleo = np.zeros(len(X), dtype=bool)
es_nucleo[db.core_sample_indices_] = True
es_frontera = (etiquetas != -1) & ~es_nucleo
es_ruido = etiquetas == -1

Para métricas como silhouette, el ruido no es un cluster. Lo quitamos antes de calcularlas, o las reportamos junto con el porcentaje de ruido.

5. Errores frecuentes

  • No escalar. eps es una distancia en las unidades de los datos. Con variables en escalas distintas, el radio solo tiene sentido en una de ellas.
  • Tratar −1 como un cluster. silhouette_score(X, db.labels_) mete todo el ruido en un mismo grupo y da un número engañoso.
  • Esperar predict. DBSCAN solo tiene fit_predict. Para puntos nuevos, un KNN entrenado sobre los puntos núcleo y sus etiquetas es una aproximación común.
  • Usarlo con densidades muy distintas. Un solo eps no sirve para un grupo denso y otro disperso a la vez. HDBSCAN, en scikit-learn desde la versión 1.3, explora todos los eps a la vez.
  • Olvidar que min_samples cuenta al propio punto. Con min_samples=1 todos los puntos son núcleo y no hay ruido.
